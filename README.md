# Chromium Extension

База расширения на Manifest V3 для Chrome, Edge, Brave и других браузеров на Chromium. Обычные HTML, CSS и JavaScript (ES-модули), без сборки и внешних зависимостей.

## Запуск

1. Откройте `chrome://extensions` (в Edge — `edge://extensions`, в Brave — `brave://extensions`).
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите корень этого проекта — папку с `manifest.json`.
4. Закрепите расширение на панели браузера и нажмите его значок.

Установка npm-пакетов для запуска не нужна. После изменения файлов нажмите **Обновить** на карточке расширения и заново откройте popup или страницу настроек.

## Что уже работает

- Popup с переключателем и переходом к настройкам.
- Отдельная страница настроек.
- Сохранение состояния в `chrome.storage.local`; открытые страницы расширения получают изменения через `storage.onChanged`.
- Фоновый service worker добавляет недостающие настройки при установке и обновлении.

Переключатель пока хранит только флаг `enabled`. При добавлении функций проверяйте его перед выполнением действий. Он не отключает расширение средствами самого браузера.

## Структура

```text
manifest.json             — описание расширения и разрешения
src/background.js         — фоновые события
src/popup/                — всплывающее окно
src/options/              — страница настроек
src/shared/settings.js    — значения по умолчанию и доступ к хранилищу
src/shared/settings-ui.js — общая логика интерфейса настроек
src/styles.css            — стили
scripts/check.mjs         — проверка проекта без зависимостей
```

## Разработка

Для проверок нужен Node.js 20 или новее:

```sh
npm run check
```

Команда проверяет синтаксис JavaScript, Manifest V3, совпадение версий и наличие локальных файлов, указанных в манифесте, HTML и импортах. Работу Chrome API проверяйте после загрузки в браузер: переключите состояние, переоткройте popup, откройте настройки и убедитесь, что значение сохранилось. Ошибки доступны на карточке расширения; консоль фона — по ссылке service worker.

Название и описание меняются в `manifest.json`; версию обновляйте также в `package.json`.

Для работы со страницами добавьте content script и ограничьте `matches` нужными сайтами. Сейчас расширение запрашивает только `storage` и не внедряет код на сайты.

## Git

Локальный репозиторий использует ветку `main`. `.gitignore` исключает зависимости, сборки, локальные настройки, секреты и ключи упаковки. Удалённый репозиторий можно подключить позже:

```sh
git remote add origin <URL-репозитория>
git push -u origin main
```

Документация: [Manifest V3 и service worker](https://developer.chrome.com/docs/extensions/develop/migrate/to-service-workers), [разрешения расширений](https://developer.chrome.com/docs/extensions/develop/concepts/declare-permissions).
