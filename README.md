# YouTube Music Queue Actions

[![Проверки](https://github.com/eQurane/ytm-enhancer/actions/workflows/check.yml/badge.svg)](https://github.com/eQurane/ytm-enhancer/actions/workflows/check.yml)

Расширение для Chrome, Edge и Brave: **лайк, дизлайк и добавление в плейлист** у каждой песни в правой очереди **Up next / Далее** на `music.youtube.com`.

Кнопки располагаются перед длительностью и не переключают воспроизведение. Без наведения видна только установленная оценка; при наведении на место оценок или фокусе с клавиатуры появляются обе кнопки. Повторное нажатие активной оценки снимает её; противоположная оценка заменяет предыдущую.

Кнопка плейлиста скрыта до наведения, пока песня не добавлена в плейлист по умолчанию. У добавленной песни видна галочка. Обычный клик добавляет песню или удаляет её из выбранного плейлиста. **Shift + клик** открывает выбор другого плейлиста; в настройках Shift можно заменить на **Ctrl** или **Alt**. Выбор другого плейлиста добавляет песню без дублей и не меняет плейлист по умолчанию, пока не отмечено «Сделать по умолчанию».

При фокусе с клавиатуры кнопки видны; работают Tab, Enter и Space, а Escape закрывает выбор. На сенсорных устройствах кнопки постоянно видны. Место под кнопки сохраняется, поэтому строка не сдвигается при наведении.

## Установка

Скачайте [ZIP с исходниками](https://github.com/eQurane/ytm-enhancer/archive/refs/heads/main.zip) и распакуйте его в постоянную папку. Или клонируйте репозиторий:

```sh
git clone https://github.com/eQurane/ytm-enhancer.git
```

1. Откройте `chrome://extensions` (Edge: `edge://extensions`, Brave: `brave://extensions`).
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку этого проекта с `manifest.json`.
4. **Перезагрузите открытую вкладку YouTube Music**, войдите в свой аккаунт и откройте очередь справа от обложки.

Нужен Chromium 111 или новее. Сборка и установка npm-пакетов не требуются. После обновления файлов нажмите **Обновить** на карточке расширения и перезагрузите вкладку музыки.

На вкладке YouTube Music нажмите иконку расширения: выберите плейлист по умолчанию и модификатор для другого плейлиста. Настройки сохраняются автоматически в этом браузере и сразу применяются во всех вкладках музыки. Пока плейлист не выбран, обычный клик по кнопке песни открывает выбор с отмеченным пунктом «Сделать по умолчанию».

Переключатель сразу убирает и восстанавливает кнопки. Те же настройки доступны через пункт «Параметры» в меню расширения; для загрузки списка плейлистов используйте иконку расширения на активной вкладке музыки. На других вкладках доступны сохранённые настройки. По умолчанию расширение включено, плейлист не выбран, модификатор — Shift.

## Как это работает

- Расширение внедряется только в `https://music.youtube.com/*`, в основной документ.
- Изолированный content script хранит настройки в `chrome.storage.local`. Между страницей и расширением передаются только предусмотренные запросы, настройки и названия/идентификаторы плейлистов; команды сайта не передаются в контекст расширения.
- Адаптер читает данные очереди и использует штатный `ytmusic-like-button-renderer`. Получение списка плейлистов — отдельный запрос чтения без параметров сохранения в последний плейлист сайта. Добавление и удаление выполняются штатными командами YouTube Music в текущей сессии.
- Наличие песни проверяется для видимых строк, включая песни, добавленные до установки расширения. Если ответ выбора не содержит состояния, читается содержимое плейлиста со всеми продолжениями. Результаты хранятся в памяти вкладки 60 секунд, повторяющиеся песни объединяются; одновременно выполняется не более трёх запросов. Перед изменением наличие песни проверяется заново.
- Подтверждённые оценки синхронизируются между повторяющимися строками и нижним плеером. На время запроса повторное действие блокируется; ошибка показывается рядом с плеером.
- Обновления DOM и проверка раз в секунду в видимой вкладке обрабатывают новые песни, переходы и повторное использование строк. Отключение удаляет элементы и останавливает наблюдение и таймер обновления.

Расширение запрашивает только `storage` и доступ content scripts к YouTube Music. Оно не читает cookies, не сохраняет токены, не требует API-ключа и не обращается к сторонним сервисам.

Удаление по галочке убирает все вхождения этой песни из плейлиста по умолчанию. При ошибке остаётся последнее подтверждённое состояние; недоступный или удалённый плейлист нужно заменить в настройках. Расширение не подставляет другой плейлист автоматически. Внешние изменения могут отобразиться с задержкой до 60 секунд; для больших плейлистов первоначальная проверка может занять больше времени.

## Совместимость и ограничения

Интеграция использует внутренние компоненты сайта, а не публичный API Google. После изменения YouTube Music адаптеру может понадобиться обновление. Если кнопки недоступны, сначала перезагрузите вкладку. Если сайт перестал возвращать нужное действие, расширение отключает соответствующую кнопку вместо выбора другой песни.

Некоторые варианты данных очереди сообщают только наличие лайка, без ранее поставленного дизлайка. В этом случае используется состояние штатного компонента и доступное состояние сессии YouTube Music; исторический дизлайк может стать видимым только после загрузки данных песни в плеер. Подтверждённые оценки, поставленные в текущей вкладке, известны всем её строкам. Счётчики лайков не добавляются.

Без входа в аккаунт или для недоступных песен действия неактивны. В первой версии расширение работает только в очереди воспроизведения, включая её строки автоподбора; страницы альбомов, поиска и библиотеки не изменяются.

## Проверка и разработка

Для проверок нужен Node.js 20+:

```sh
npm run check
```

Зависимостей нет, `npm install` не требуется. GitHub Actions запускает эту же команду на Node.js 22 и 24 при push и pull request в `main`.

Проверяются синтаксис, Manifest V3, версии, локальные ресурсы, точный домен внедрения, команды и страницы плейлистов, кэш и ограничение запросов, обработка ошибок и гонки настроек. Тесты используют фикстуры, не меняют ваш аккаунт и не делают сетевых запросов.

Для визуального стенда со смоделированными компонентами сайта:

```sh
node scripts/preview.mjs
```

Откройте `http://127.0.0.1:4173/tests/fixtures/queue.html`. Стенд позволяет выбрать плейлист и модификатор, проверить историческое наличие песен, скрытие кнопок, дубли, замену строки, ошибки и отключение без установки расширения. Он не заменяет проверку интеграции с настоящим YouTube Music.

После установки проверьте в YouTube Music:

- Лайк → снять лайк → дизлайк → снять дизлайк для текущей и другой песни.
- Согласованность оценок в очереди, повторяющихся строках и нижнем плеере.
- Первое добавление открывает выбор для нажатой песни; после выбора плейлиста обычный клик добавляет или удаляет песню. Повторяющиеся строки показывают одинаковые галочки, воспроизведение не переключается.
- Выбор другого плейлиста по Shift/Ctrl/Alt + клик не меняет плейлист по умолчанию без отметки «Сделать по умолчанию» и не создаёт дубли.
- Всплывающее окно у иконки расширения загружает список на вкладке музыки; настройка сохраняется после перезагрузки, удалённый плейлист не заменяется автоматически.
- Прокрутку, смену очереди, переходы без перезагрузки, длинные названия и узкую панель.
- Навигацию Tab, активацию Enter/Space и включение/отключение через настройки расширения.
- При ошибке сети не остаётся ложной успешной оценки, доступна повторная попытка.

Ошибки расширения доступны на его карточке, сообщения адаптера — в консоли вкладки YouTube Music.

## Сообщить о проблеме

Создайте [issue](https://github.com/eQurane/ytm-enhancer/issues), указав версию расширения, браузер и шаги воспроизведения. Перед публикацией сообщений консоли удалите данные аккаунта, идентификаторы личных плейлистов и токены сессии.

Проект не связан с Google или YouTube.
