# YouTube Music Queue Actions

Расширение для Chrome, Edge и Brave: **лайк, дизлайк и добавление в плейлист** у каждой песни в правой очереди **Up next / Далее** на `music.youtube.com`.

Кнопки постоянно видны перед длительностью. Оценивать и сохранять можно другую песню, не переключая воспроизведение. Повторное нажатие активной оценки снимает её; противоположная оценка заменяет предыдущую. Добавление использует штатное поведение YouTube Music: сайт открывает окно выбора плейлиста или сохраняет песню в последний выбранный плейлист. Успешное добавление без окна не считается ошибкой.

## Установка

1. Откройте `chrome://extensions` (Edge: `edge://extensions`, Brave: `brave://extensions`).
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку этого проекта с `manifest.json`.
4. **Перезагрузите открытую вкладку YouTube Music**, войдите в свой аккаунт и откройте очередь справа от обложки.

Нужен Chromium 111 или новее. Сборка и установка npm-пакетов не требуются. После обновления файлов нажмите **Обновить** на карточке расширения и перезагрузите вкладку музыки.

Переключатель в настройках расширения сразу убирает и восстанавливает кнопки во всех открытых вкладках музыки. Откройте настройки через пункт «Параметры» в меню расширения. По умолчанию расширение включено.

## Как это работает

- Расширение внедряется только в `https://music.youtube.com/*`, в основной документ.
- Изолированный content script читает `chrome.storage.local` и передаёт странице только флаг включения.
- Адаптер в контексте страницы читает данные строк очереди и использует штатный `ytmusic-like-button-renderer`. Запросы и окно плейлистов обслуживает сам YouTube Music в текущей сессии.
- Подтверждённые оценки синхронизируются между повторяющимися строками и нижним плеером. На время запроса повторное действие блокируется; ошибка показывается рядом с плеером.
- Обновления DOM и проверка раз в секунду в видимой вкладке обрабатывают новые песни, переходы и повторное использование строк. Отключение удаляет элементы и останавливает наблюдение и таймер обновления.

Расширение запрашивает только `storage` и доступ content scripts к YouTube Music. Оно не читает cookies, не сохраняет токены, не требует API-ключа и не обращается к сторонним сервисам.

## Совместимость и ограничения

Интеграция использует внутренние компоненты сайта, а не публичный API Google. После изменения YouTube Music адаптеру может понадобиться обновление. Если кнопки недоступны, сначала перезагрузите вкладку. Если сайт перестал возвращать нужное действие, расширение отключает соответствующую кнопку вместо выбора другой песни.

Некоторые варианты данных очереди сообщают только наличие лайка, без ранее поставленного дизлайка. В этом случае используется состояние штатного компонента и доступное состояние сессии YouTube Music; исторический дизлайк может стать видимым только после загрузки данных песни в плеер. Подтверждённые оценки, поставленные в текущей вкладке, известны всем её строкам. Счётчики лайков не добавляются.

Без входа в аккаунт или для недоступных песен действия неактивны. В первой версии расширение работает только в очереди воспроизведения, включая её строки автоподбора; страницы альбомов, поиска и библиотеки не изменяются.

## Проверка и разработка

Для проверок нужен Node.js 20+:

```sh
npm run check
```

Проверяются синтаксис, Manifest V3, версии, локальные ресурсы, точный домен внедрения, адаптер данных, обработка ответов и гонка чтения настроек. Тесты используют фикстуры, не меняют ваш аккаунт и не делают сетевых запросов.

Для визуального стенда со смоделированными компонентами сайта:

```sh
node scripts/preview.mjs
```

Откройте `http://127.0.0.1:4173/tests/fixtures/queue.html`. Стенд позволяет проверить расположение, дубли песен, замену данных строки, ошибки и отключение без установки расширения. Он не заменяет проверку интеграции с настоящим YouTube Music.

После установки проверьте в YouTube Music:

- Лайк → снять лайк → дизлайк → снять дизлайк для текущей и другой песни.
- Согласованность оценок в очереди, повторяющихся строках и нижнем плеере.
- Первое добавление открывает окно для нажатой песни; последующие добавления в запомненный плейлист не вызывают ложной ошибки или повторного запроса. Текущая музыка продолжает играть.
- Прокрутку, смену очереди, переходы без перезагрузки, длинные названия и узкую панель.
- Навигацию Tab, активацию Enter/Space и включение/отключение через настройки расширения.
- При ошибке сети не остаётся ложной успешной оценки, доступна повторная попытка.

Ошибки расширения доступны на его карточке, сообщения адаптера — в консоли вкладки YouTube Music.
