# YTM Enhancer

[![Проверки](https://github.com/eQurane/ytm-enhancer/actions/workflows/check.yml/badge.svg)](https://github.com/eQurane/ytm-enhancer/actions/workflows/check.yml)

Расширение для Chrome, Edge и Brave, которое добавляет удобное управление в YouTube Music.

- **Лайк и дизлайк** у каждой песни в правой очереди **Up next / Далее**.
- **Плейлисты** — добавление и удаление песен прямо из очереди.
- **Точная громкость** — постоянно видимая шкала, управление колесом и поле ввода с шагом 0,5 пункта.

## Установка

Нужен Chromium 111 или новее. Сборка и установка npm-пакетов не требуются.

1. Откройте [последний релиз](https://github.com/eQurane/ytm-enhancer/releases/latest), скачайте **`ytm-enhancer-<версия>.zip`** в разделе **Assets** и распакуйте в постоянную папку.
2. Откройте `chrome://extensions` (Edge: `edge://extensions`, Brave: `brave://extensions`) и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите распакованную папку с `manifest.json`.
4. **Перезагрузите вкладку `music.youtube.com`**, войдите в аккаунт и откройте очередь справа от обложки.

Для обновления скачайте новый архив, обновите файлы в папке расширения, нажмите **Обновить** на его карточке и перезагрузите вкладку музыки.

## Как пользоваться

Наведите курсор на песню в очереди, чтобы увидеть кнопки. Повторный клик по активной оценке снимает её. Кнопки не переключают воспроизведение.

Обычный клик по кнопке плейлиста добавляет или удаляет песню; при первом использовании открывается выбор плейлиста. **Shift + клик** открывает выбор другого плейлиста. Плейлист по умолчанию, модификатор и включение расширения настраиваются через его иконку на вкладке YouTube Music.

В нижнем плеере меняйте громкость колесом или введите процент в поле и нажмите **Enter**.
